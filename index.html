선택한 행이 각 열과 어떻게 연결되는지 확인합니다. 산업 행뿐 아니라 원표의 합계·분석지표 행도 포함됩니다.

기본 자료를 불러온 후 표시됩니다.
열 코드열 이름원자료 값

스크롤하여 전체 열을 볼 수 있습니다. 금액표의 일반 데이터 단위는 백만원입니다. 구성비·유발계수 등 요약 행은 행 명칭을 우선 확인하세요.

2. 국내 생산물 최종수요 증가 시뮬레이션

수입 완제품 구매를 제외한 국내 생산물 최종수요 증가를 입력하세요. 여러 산업의 증가액은 합산됩니다.

1,000백만원 = 10억원. 이번 버전은 양의 수요 증가만 지원합니다.

    시나리오를 추가하세요.

    생산유발액 상위 15개 산업

    산업별 유발액 — 백만원, 생산유발액 내림차순
    코드산업생산수입부가가치

    3. 시나리오 비교 분석

    파급효과 계산 후 결과를 저장해 서로 다른 산업의 동일한 최종수요 증가가 가져오는 효과를 비교합니다. 모든 금액은 백만원입니다.

    저장된 비교 결과가 없습니다.

    시나리오별 총 파급효과 비교 (백만원, 배수는 무차원)
    시나리오산업분류대상 산업수요 증가생산유발수입유발부가가치유발생산유발배수수입유발률 (%)부가가치유발률 (%)삭제

    수요 1백만원당 유발효과 비교

    생산은 배수, 수입·부가가치는 최종수요 대비 비율입니다. 서로 다른 수요 규모도 비교할 수 있습니다.

    생산유발배수 비교

    산업 간 파급효과 차이를 비교하는 탐색 도구입니다. 유발효과는 모형에 따른 추정치이며 실제 관측된 인과효과가 아닙니다.

    4. 산업별 영향력계수·감응도계수 분석

    선택한 산업분류의 국산 생산유발계수 행렬을 이용하여 산업 간 연관도를 비교합니다. 평균 1을 기준으로 1보다 크면 전체 산업 평균보다 높은 수준입니다.

    선택한 분류를 먼저 불러오세요.

    전후방 연관관계 사분면

    가로: 영향력계수 / 세로: 감응도계수 · 기준선 1 · 점에 마우스를 올리면 산업명이 표시됩니다.

    영향력계수 및 감응도계수 (무차원)
    코드산업영향력계수감응도계수후방연쇄(열합)전방연쇄(행합)

    영향력계수 = 해당 산업 생산유발계수 열합 / 전체 열합의 평균. 감응도계수 = 해당 산업 생산유발계수 행합 / 전체 행합의 평균. 원자료의 국산 생산유발계수 기준이며 두 계수는 무차원입니다. 감응도는 모든 산업의 최종수요가 동일하게 증가하는 가상 조건에서의 상대적 반응 지표입니다.

    5. 자료 및 분석 범위 안내

    기본 데이터: 한국은행 2023년 생산자가격 통합대·중·소분류 및 기본부문 산업연관표. 원본 Excel에 포함된 12개 시트를 탐색할 수 있습니다.

    분석 범위: 산업분류별 공식 원본 엑셀의 계수행렬을 각각 사용합니다. 분류를 변경하면 데이터를 다시 불러와야 합니다. 서로 다른 분류의 결과는 산업 구성이 달라 직접 비교할 때 주의가 필요합니다.

    산식: 생산유발액 = 생산유발계수 행렬 × 국내 최종수요 증가 벡터. 수입 및 부가가치유발액도 해당 계수행렬을 사용합니다. 결과는 백만원, 생산유발배수는 배입니다.
