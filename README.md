# 2023년 산업연관표 분석 웹앱

한국은행 2023년 연장 산업연관표(생산자가격)의 **통합대분류·통합중분류·통합소분류·기본부문** 원본을 사용합니다.

## 사용법
1. 산업분류를 선택하고 **선택 분류 불러오기**를 누릅니다. 각 분류별 원본 엑셀 12개 시트를 검색할 수 있습니다.
2. 산업과 국내 생산물 최종수요 증가액(백만원)을 선택하여 시나리오에 추가하고 **파급효과 계산**을 누릅니다.
3. 결과표·상위 15개 산업 그래프·CSV 다운로드를 확인합니다.
4. **산업 연관도 계산**으로 영향력계수(열합/평균열합), 감응도계수(행합/평균열합)를 확인합니다.
5. 분류 변경 시 반드시 해당 분류를 다시 불러옵니다.

## 계산식
- 생산유발액: 국산 생산유발계수행렬 × 국내 최종수요 증가 벡터
- 수입유발액: 수입유발계수행렬 × 동일 벡터
- 부가가치유발액: 부가가치유발계수행렬 × 동일 벡터
- 영향력계수: 생산유발계수 열합 ÷ 전체 산업 평균 열합
- 감응도계수: 생산유발계수 행합 ÷ 전체 산업 평균 열합
- 금액: 백만원. 계수: 무차원. 배수: 배.

## 출처 및 주의
한국은행 경제통계시스템(ECOS), 2023년 연장 산업연관표, 투입산출표 생산자가격 통합대·중·소분류 및 기본부문. 원본 파일은 `data/`에 저장. 분류별 공식 계수표를 사용하며, 기본부문을 임의 합산해 분류별 유발계수를 만들지 않습니다. 수요충격 결과는 고정계수 모형의 추정치로 실제 인과효과를 보장하지 않습니다. 공개 저장소에 비밀번호 및 개인정보를 업로드하지 마세요.

## 추가 분석 대시보드
- 시나리오 비교에서 수입유발률 = 수입유발액 / 국내 최종수요 증가액 × 100, 부가가치유발률 = 부가가치유발액 / 국내 최종수요 증가액 × 100. 생산유발배수와 함께 수요 규모를 정규화하여 비교합니다.
- 연관도 사분면: 가로 영향력계수, 세로 감응도계수, 기준 1. 검색 결과의 산업 점과 유형별 개수를 표시합니다. 점에 마우스를 올리면 산업명과 계수를 확인할 수 있습니다.
- 시나리오 비교 및 연관도 CSV, 사분면 SVG 저장을 지원합니다. 분석 결과는 세션 내에서 유지됩니다.
- 출처: 한국은행 경제통계시스템 https://ecos.bok.or.kr/ (2023년 연장 산업연관표). 원자료의 재배포 조건은 게시자가 확인해야 합니다.
